## The entry

> Earth review: they throw a party every year just for surviving another trip around the sun. Honestly, fair. 5/5, cake was excellent.

132 characters, one line. The whole joke is a single alien reframe — a
birthday is a party for surviving another trip around the sun — with the
verdict ("Honestly, fair") and a tourist's closing remark (the cake) landing
at the end. No traffic, no gravity, no money, no weather: just one ordinary
Earth habit seen from outside, written the way a tourist would leave it.

## How it works

`main.ts` writes the single winning line to `/output/entry.txt`. Nothing
else: no input, no network, no randomness. The output is byte-identical on
every run.

Run it with Node:

```sh
node main.ts
cat /output/entry.txt
```
